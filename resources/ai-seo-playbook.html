Inside the playbook

3 systems. Every prompt. Copy & paste.

This isn't theory. It's three text files with every prompt, every step. Built by an operator with zero coding experience. Copy them, swap in your business details, ship them this week.

System 01

The AI recommendation system (llms.txt)

The exact llms.txt file, schema markup, robots.txt config, FAQ blocks, and location pages used to get ChatGPT, Claude, and Perplexity to actively recommend a business by name. This is the one that took traffic from 7 to 150 visitors a day.

System 02

Markdown mirrors

Generate a clean, plain-text version of every page on your site so AI can quote you faster, more accurately, and more often. Almost nobody is doing this yet - that's the opportunity. Built in about an hour with one Python script.

System 03

Sitemaps + Google Search Console

Tell Google exactly which pages matter, then see your actual ranking data - which keywords you rank for, what position you're in, and where the quick wins are. The third file that ties the whole system together.
